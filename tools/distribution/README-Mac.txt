FAUMONIA 8.0 DLA macOS
https://faumonia.pl/

1. Zainstaluj Javę 8 lub nowszą dla swojego Maca, jeśli jej nie masz.
   Dobierz wydanie do procesora: Intel (x64) albo Apple Silicon (aarch64).
   Java nie jest dołączona do paczki gry.
   Pobieranie Javy: https://adoptium.net/temurin/releases/

2. Rozpakuj cały ZIP do folderu, do którego masz prawo zapisu, np. Dokumenty.
   Zachowaj folder lib obok pliku FaumoniaOnline.jar.

3. Uruchom Start.command. Skrypt znajdzie Javę i uruchomi grę.
   Jeśli wystąpi błąd, informacja pozostanie w oknie Terminala.

Jeśli rozpakowanie ZIP-a nie zachowa prawa wykonywania Start.command,
otwórz Terminal, wpisz chmod +x ze spacją na końcu, przeciągnij do okna
plik Start.command i naciśnij Enter. Potem ponownie uruchom ten plik.

Jeśli macOS blokuje otwarcie pobranej aplikacji, sprawdź komunikat systemu
oraz instrukcję Apple: https://support.apple.com/pl-pl/102445.

Nie trzeba zmieniać adresu serwera. W grze wybierz istniejące konto
lub utwórz nowe. Pomoc: https://faumonia.pl/.

Licencje gry i użytych bibliotek znajdują się w folderach doc i lib.

FAUMONIA 8.0
https://faumonia.pl/

Gra wymaga Javy 8 lub nowszej. Java nie jest dołączona do tej paczki.
Możesz ją pobrać ze strony https://www.java.com/pl/download/.

INSTALATOR EXE
Zamknij grę, uruchom instalator i wykonaj kolejne kroki.
Po instalacji uruchom Faumonię ze skrótu na pulpicie lub w menu Start.

PACZKA ZIP
Rozpakuj cały ZIP do jednego folderu. Uruchom plik FaumoniaOnline.jar.
Folder lib musi pozostać obok niego. Nie uruchamiaj gry z wnętrza archiwum.

Jeśli dwuklik otwiera archiwizator lub nie uruchamia gry, skorzystaj
z pliku Uruchom-Faumonie.bat znajdującego się obok JAR-a.

Nie kopiuj pojedynczego JAR-a do folderu starej wersji. Korzystaj z całej
nowej paczki albo instalatora, aby wszystkie biblioteki do siebie pasowały.

W grze wybierz istniejące konto lub utwórz nowe. Zachowaj dane logowania.
Pomoc i informacje o grze: https://faumonia.pl/.

Licencje gry i użytych bibliotek znajdują się w folderach doc i lib.
